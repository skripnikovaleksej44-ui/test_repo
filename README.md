# Автоматизация тестирования REST API (Курсовой проект)

Проект посвящен разработке автотестов для проверки серверной части (Бэкенда) приложения и тестирования веб-инструментов.

## 🛠 Стек технологий
- **Язык программирования**: Python
- **Фреймворки и библиотеки**: PyTest, Requests
- **Тестирование API**: Postman
- **Отчеты и логирование**: Allure Report

## 📋 Что было протестировано
- Позитивные и негативные сценарии отправки REST-запросов (GET, POST, PUT, DELETE).
- Валидация статус-кодов ответов сервера (200 OK, 201 Created, 400 Bad Request и др.).
- Проверка структуры и корректности JSON-данных в теле ответов.

## 🚀 Как запустить тесты
1. Клонировать репозиторий:
`git clone https://github.com`
2. Установить необходимые зависимости:
`pip install -r requirements.txt`
3. Запустить выполнение тестов:
`pytest`
